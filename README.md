# 知行题库 · 北森考测专项练习

一个基于 React + Vite 构建的北森测评题库练习平台，支持三大专项（言语理解、资料分析、图形推理），多账户隔离，进度持久化。

## 功能特性

- **三大专项练习** — 言语理解与表达（40 题）、资料分析（253 题）、图形推理（152 题），共 445 道精选题目
- **即时反馈** — 提交答案后立即显示正确/错误标记与详细解析
- **多账户隔离** — 基于 localStorage 的注册/登录系统，不同用户进度互不干扰
- **进度持久化** — 自动保存作答记录、错题本、收藏夹，刷新不丢失
- **错题重练** — 专项复习错题，针对性强化薄弱环节
- **收藏题目** — 随时收藏重点题目，便于回顾
- **答题卡导航** — 网格状答题卡，一目了然掌握全局进度
- **图片支持** — 资料分析题和图形推理题内置原题图片，图文并茂

## 开始使用

### 环境要求

- Node.js 18+
- npm 或 pnpm

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

启动后在浏览器打开 `http://localhost:5173` 即可使用。

## 数据来源

题目数据来源于《2024 北森测评题库整理》，包含三大专项：

| 专项 | 题数 | 特性 |
|------|------|------|
| 言语理解与表达 | 40 | 纯文本选择，片段阅读、逻辑填空、语句表达 |
| 资料分析 | 253 | 配有统计图表/表格图片，图表阅读、数据计算、综合分析 |
| 图形推理 | 152 | 配有题干/选项图片，规律识别、空间想象、图形重组 |

## 技术栈

- **React 19** — UI 框架
- **Vite 8** — 构建工具
- **lucide-react** — 图标库
- 纯 CSS — 样式方案（无第三方 UI 库）

## 图片映射说明

资料分析题采用 **"题干文本定位 + 答案块区间匹配"** 策略进行题图关联：

1. 提取 DOCX 文档中所有文本段落与图片引用
2. 按题干文本定位每道题在文档中的位置
3. 将文档按"正确答案"标记划分为答案块区间
4. 每道题的图片 = 其所在答案块区间内的所有图片

图形推理题按文档顺序逐题分配图片，经逐字节验证与原始 DOCX 完全一致。
